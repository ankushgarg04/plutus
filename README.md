# plutus

Modern Python project scaffold.

## Setup

1. Create a virtual environment (recommended):

```bash
python3 -m venv .venv
source .venv/bin/activate  # macOS / Linux
# .venv\Scripts\activate   # Windows PowerShell
```

2. Install the project in editable mode:

```bash
pip install -e ".[dev]"
```

3. Run tests:

```bash
pytest
```

## Project layout

- `src/plutus/` – main package code  
- `tests/` – test suite
